# CRC_adenoma_code
## 🔧 Software Environment

This study was conducted using the following software tools and versions for metagenomic data preprocessing and taxonomic profiling:

| Tool    | Version | Description |
|---------|--------|-------------|
| fastp   | 1.0.1  | Quality control and read preprocessing |
| Bowtie2 | 2.5.4  | Host read removal / sequence alignment |
| Kraken2 | 2.17.1 | Taxonomic classification microbial reference database GTDB v220|
| Bracken | 3.1    | Abundance estimation refinement |
| R   | 4.3.1  | idopNetwork contribution |
| Python   | 3.1.1  | data clean |
